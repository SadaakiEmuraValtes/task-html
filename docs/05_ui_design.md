# 画面設計書

**プロジェクト名:** task-html — タスク管理カンバンボード
**作成日:** 2026-03-15
**バージョン:** 1.0

---

## 1. 画面構成

アプリは単一画面（SPA）で構成される。モーダルは同一画面上にオーバーレイ表示する。

```
┌──────────────────────────────────────────────────────────────┐
│ ヘッダー                                                      │
│  [📋 タスク管理ボード]  [件数バッジ×3]  [フィルタバー]  [追加] │
├──────────────────────────────────────────────────────────────┤
│ カンバンボード                                                 │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐                  │
│  │ 未着手   │  │ 進行中   │  │ 完了     │                  │
│  │ ─────── │  │ ─────── │  │ ─────── │                  │
│  │ [カード] │  │ [カード] │  │ [カード] │                  │
│  │ [カード] │  │         │  │         │                  │
│  └──────────┘  └──────────┘  └──────────┘                  │
└──────────────────────────────────────────────────────────────┘
```

---

## 2. ヘッダー

### レイアウト
- 高さ: 64px、sticky（スクロールしても固定）
- 背景: `#fff`、下ボーダー: `#e2e8f0`

### 要素（左から右）

| 要素 | 内容 |
|------|------|
| ロゴ | 📋 タスク管理ボード（h1、20px bold） |
| 件数バッジ | 列ごとに「未着手 N」「進行中 N」「完了 N」（列カラーのボーダー・テキスト） |
| フィルタバー | すべて / 高優先度 / 中優先度 / 低優先度 のボタン |
| タスク追加ボタン | 「＋ タスク追加」（紫 `#6366f1`） |

### フィルタバーの動作

| 操作 | 結果 |
|------|------|
| 「すべて」クリック | フィルタ解除（常に `'all'` にセット） |
| 優先度ボタンクリック（未選択→選択） | その優先度でフィルタ（選択中はカラー背景） |
| 優先度ボタンクリック（選択中→再クリック） | フィルタ解除（`'all'` に戻す） |

## 3. カンバンボード

### カラム

| 項目 | 仕様 |
|------|------|
| 列数 | 3列（未着手 / 進行中 / 完了） |
| レイアウト | CSS Grid、`grid-template-columns: repeat(3, 1fr)` |
| 最小幅 | 720px |
| 背景 | `#fff`、`border-radius: 12px` |
| ドロップ時 | 列カラーのボーダー＋グロー（`column--over`） |
| 空状態 | 「タスクなし」を破線ボーダーのプレースホルダに表示 |

### カラムヘッダー

```
● 未着手  [3]
─────────────
```

- カラードット（列カラー）+ ラベル + 件数バッジ（グレー）

## 4. タスクカード

### 構造

```
┌──────────────────────────────────────┐
│ [高] ▌              [◀] [▶] [✏] [✕] │  ← ヘッダー行
│ タスクタイトル                        │  ← タイトル
│ 説明テキスト（任意）                  │  ← 説明
│ 2026/03/15          ✓ 完了           │  ← フッター行
└──────────────────────────────────────┘
```

### 各要素

| 要素 | 仕様 |
|------|------|
| 優先度バッジ | 優先度カラーの背景（22% 不透明）＋テキスト。クリックでドロップダウン表示 |
| ◀ ボタン | 左の列へ移動。最左列では非表示 |
| ▶ ボタン | 右の列へ移動。最右列では非表示 |
| ✏ ボタン | 編集モーダルを開く（ホバー: 青背景） |
| ✕ ボタン | タスク削除（ホバー: 赤背景） |
| タイトル | 14px / bold。完了列では取り消し線 |
| 説明 | 13px / グレー。空の場合は非表示 |
| 作成日 | 11px / `ja-JP` ロケール形式（例: 2026/3/15） |
| ✓完了バッジ | 完了列のみ表示（緑） |

### 状態別スタイル

| 状態 | スタイル |
|------|---------|
| 通常 | 白背景、薄いグレーボーダー |
| ホバー | 影が濃くなる、1px 上に浮く |
| ドラッグ中 | opacity 0.4、scale 0.97 |
| 完了列 | 薄緑背景、緑ボーダー、タイトルに取り消し線 |

### 優先度ドロップダウン

- 優先度バッジのクリックで表示
- `onMouseLeave` で自動的に閉じる
- 選択するとその優先度に即時変更（localStorage 保存）

## 5. タスク追加モーダル

### 表示条件
「＋ タスク追加」ボタンクリックで表示

### レイアウト

```
┌──────────────────────────────────┐
│ タスクを追加               [✕]   │
├──────────────────────────────────┤
│ タイトル *                        │
│ [                              ] │
│                                  │
│ 説明                             │
│ [                              ] │
│ [                              ] │
│ [                              ] │
│                                  │
│ 優先度                           │
│ [高優先度] [中優先度] [低優先度]  │
│                                  │
│              [キャンセル] [追加する] │
└──────────────────────────────────┘
```

### フィールド仕様

| フィールド | 種別 | 初期値 | バリデーション |
|-----------|------|--------|--------------|
| タイトル | text | 空 | 必須・最大80文字。空の場合「追加する」ボタンが disabled |
| 説明 | textarea (3行) | 空 | 任意・最大300文字 |
| 優先度 | ボタングループ | 中 | 必須（常にいずれかが選択） |

### 閉じる操作

| 操作 | 結果 |
|------|------|
| ✕ ボタン | 閉じる |
| キャンセルボタン | 閉じる |
| Escape キー | 閉じる |
| オーバーレイクリック | 閉じる |

---

## 6. タスク編集モーダル

### 表示条件
タスクカードの ✏ ボタンクリックで表示

### 追加モーダルとの差分

| 項目 | 追加モーダル | 編集モーダル |
|------|------------|------------|
| タイトル | 「タスクを追加」 | 「タスクを編集」 |
| 初期値 | 空 | 既存タスクの値 |
| タイトルフォーカス | フォーカスのみ | フォーカス＋全選択 |
| 送信ボタン | 「追加する」 | 「保存する」 |
| 送信先 | `onAdd` | `onEdit` |

## 8. レスポンシブ対応

| 画面幅 | 挙動 |
|--------|------|
| 1024px 以上 | 3列が均等幅で表示 |
| 720px ～ 1024px | 3列を横スクロールで表示（min-width: 720px） |
| 720px 未満 | 横スクロール（現時点でモバイル最適化は対象外） |
