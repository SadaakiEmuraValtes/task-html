# 要件定義書

**プロジェクト名:** task-html — タスク管理カンバンボード
**作成日:** 2026-03-15
**バージョン:** 1.0

---

## 1. 目的

個人またはチームのタスクを視覚的に管理するカンバンボード形式のWebアプリケーション。
シンプルな操作でタスクの作成・進捗管理・優先度管理を実現する。

---

## 2. 対象ユーザー

- 個人の作業タスクを管理したいユーザー
- ブラウザのみで完結するツールを必要とするユーザー
- サーバー不要・ローカル動作を求めるユーザー

---

## 3. 機能要件

### 3.1 タスク管理

| ID | 機能 | 説明 | 優先度 |
|----|------|------|--------|
| F-01 | タスク追加 | タイトル・説明・優先度を指定してタスクを作成する | 必須 |
| F-02 | タスク編集 | 既存タスクのタイトル・説明・優先度を変更する | 必須 |
| F-03 | タスク削除 | タスクを削除する（確認ダイアログなし） | 必須 |
| F-04 | タスク完了 | 「完了」列に移動することで完了状態を表現する | 必須 |

### 3.2 カンバンボード

| ID | 機能 | 説明 | 優先度 |
|----|------|------|--------|
| F-05 | 3列表示 | 未着手 / 進行中 / 完了 の3列を横並びで表示する | 必須 |
| F-06 | ドラッグ&ドロップ移動 | タスクカードをドラッグして別列に移動する | 必須 |
| F-07 | ボタン移動 | ◀ ▶ ボタンで隣の列へ移動する | 必須 |
| F-08 | 列内件数表示 | 各列のヘッダーにタスク件数を表示する | 推奨 |
| F-09 | 空列表示 | タスクがない列に「タスクなし」を表示する | 推奨 |

### 3.3 優先度

| ID | 機能 | 説明 | 優先度 |
|----|------|------|--------|
| F-10 | 優先度設定 | 高 / 中 / 低 の3段階で優先度を設定する | 必須 |
| F-11 | 優先度変更 | タスクカード上の優先度バッジから直接変更する | 必須 |
| F-12 | 優先度フィルタ | 指定した優先度のタスクのみを全列に表示する | 必須 |

### 3.4 データ永続化

| ID | 機能 | 説明 | 優先度 |
|----|------|------|--------|
| F-13 | 自動保存 | 操作のたびに localStorage へ自動保存する | 必須 |
| F-14 | 初回サンプル | 初回アクセス時（localStorage 未保存）にサンプルデータを表示する | 推奨 |

---

## 4. 非機能要件

| 項目 | 要件 |
|------|------|
| 動作環境 | モダンブラウザ（Chrome / Edge / Firefox 最新版） |
| 配信方式 | GitHub Pages（静的ファイル配信） |
| サーバー依存 | なし（全機能をクライアントサイドで完結） |
| レスポンス | 操作に対して即時反映（ローディング演出なし） |
| 最小画面幅 | 720px（ボードの `min-width`） |

---

## 5. 制約事項

- タスクの共有・同期機能は対象外（localStorage はブラウザ単位）
- ユーザー認証・アカウント管理は対象外
- タスクの期限・通知機能は対象外
- オフライン対応（Service Worker）は対象外

---

## 6. 入力バリデーション

| フィールド | 制約 |
|-----------|------|
| タイトル | 必須、最大80文字 |
| 説明 | 任意、最大300文字 |
| 優先度 | 必須、高/中/低のいずれか（デフォルト: 中） |
